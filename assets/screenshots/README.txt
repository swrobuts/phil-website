Phil Dashboard Screenshots
==========================

IMPORTANT — PRIVACY: Before adding screenshots, blur all personal data:
  - Email sender names and addresses
  - Subject lines with personal content
  - Calendar participant names
  - Any real task or mail content
  Tools: macOS Preview > Markup > Blur, GIMP, or Pixelmator.

Add 3-5 screenshots of the running Phil application here:

  dashboard.png   — Full dashboard overview (mail counts, calendar, tasks)
  mail-triage.png — Mail triage list with category badges
  chat.png        — Phil chat in action (streaming response)
  memory.png      — Memory view with stored facts (optional)

How to take screenshots:
  1. Run Phil locally (see docs/setup.md)
  2. Open http://localhost:5173
  3. Take screenshots at 1280x800 or similar widescreen resolution
  4. Blur all real personal data (see note above)
  5. Crop to show the key UI area
  6. Save as PNG, max ~200KB per file
