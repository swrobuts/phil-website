Intellectual Lineage

Every idea has ancestors.

The Knowledge Navigator crystallised fifty years of visionary thinking. From index cards to artificial intelligence, here is the lineage that made Phil possible.

1935

Mundaneum · Paul Otlet

A global knowledge network on 16 million index cards — an analogue internet.

1937

World Brain · H.G. Wells

A living, continuously updated world encyclopaedia accessible to all.

1945

Memex · Vannevar Bush

A desk that stores and links documents associatively — conceptual hypertext, 1945.

1950

Turing Test · Alan Turing

Can machines think? The measure for artificial intelligence to this day.

1955

Artificial Intelligence · John McCarthy

Coined the term at Dartmouth. Set the research agenda for everything that followed.

1960

Man–Computer Symbiosis · J.C.R. Licklider

Interactive cooperation between human and machine — augmentation, not automation.

1963

Sketchpad · Ivan Sutherland

First interactive graphics system. Direct manipulation decades before the mouse.

1966

ELIZA · Joseph Weizenbaum

First chatbot — and a warning about how readily people attribute understanding to machines.

1968

Mother of All Demos · Douglas Engelbart

Mouse, windows, hypertext, video conferencing — demonstrated live, all at once.

1972

Dynabook · Alan Kay

A portable personal computer for children — the iPad, 38 years early.

1974

Xanadu · Ted Nelson

Invented "hypertext". Designed a global non-hierarchical document network.

1986

Society of Mind · Marvin Minsky

Intelligence as emergent from many simple agents — the architecture of today's LLMs.

1987

Knowledge Navigator · John Sculley / Apple

United fifty years of visionary thinking into a 9-minute concept video. Named the assistant Phil.

1987 – 2022

The Gap —
And the Attempt

The vision was clear. The technology was not. Apple tried honestly — the Newton MessagePad in 1993. It failed because the decade was wrong. The Newton is not a failure story. It is proof the idea was worth pursuing.

Vision (1987)

Knowledge Navigator

  • Intelligent AI agent with natural language
  • Global knowledge access via network
  • Touch interaction — tablet form factor
  • Personalised, learns from the user
Reality (1993)

Apple Newton

  • $699 entry price — unclear value proposition
  • Handwriting recognition failed publicly
  • No internet, no wireless, no ecosystem
  • Released 14 months before it was ready

Phil 2026

Today, the technology
finally caught up.

Phil is a working personal information manager — not a concept video. It manages email, calendar, tasks and knowledge using today's AI tools. It does not do everything Apple envisioned. It does what matters most, right now.

01
Mail Triage

Phil reads your inbox and categorises every message: VIP / Action Required / FYI / Noise. Each mail gets a 2-sentence summary and a concrete action recommendation. Powered by Claude.

Learn more →
02
Dashboard

A daily briefing at a glance: unread mail counts by category, today's calendar events, pending tasks, and analytical tiles showing communication patterns over time.

Learn more →
03
Calendar

Natural-language calendar search across a full year of events. Ask "What's next week?" or "When is the faculty meeting?" Phil fetches the context and answers — no hallucinations.

Learn more →
04
Meeting Preparation

Given a calendar event, Phil identifies participants, retrieves related emails via semantic search, and drafts a structured briefing: attendees, relevant messages, agenda suggestion.

Learn more →
05
Memory & Learning

Phil remembers facts about you across sessions, stored in SQLite and ChromaDB. Thumbs up/down feedback drives RLHF-style learning. All facts are visible and editable.

Learn more →
06
Semantic Search

Emails and PDF/DOCX attachments are indexed in a vector store. Phil retrieves semantically similar past correspondence even when keyword search fails.

Learn more →

Hybrid AI

Phil thinks locally —
or in the cloud.

By default, Phil uses Anthropic's Claude API for the highest quality results. But it can also run entirely on local hardware — no data leaves your machine, no API costs, full privacy.

Cloud

Anthropic Claude

Default mode. Highest reasoning quality, instant setup. Requires an Anthropic API key.

ANTHROPIC_API_KEY=sk-ant-...
  • Claude Sonnet / Haiku — streaming via SSE
  • Best quality for triage, briefing, memory
  • No local GPU required
Local

LM Studio + Open-Source LLM

Run a powerful open-source model entirely on your own hardware. Zero API costs, full data sovereignty.

LOCAL_LLM_ENDPOINT=http://localhost:1234/v1 LOCAL_LLM_MODEL=qwen2.5-32b-instruct
  • Qwen2.5-32B · Llama 3.3 70B · Mistral
  • Automatic fallback to cloud if unavailable
  • 16 GB VRAM or Apple Silicon M-series

Tested Hardware

Apple M3 Pro · 18 GB unified Apple M2 Ultra · 192 GB unified NVIDIA RTX 4090 · 24 GB VRAM NVIDIA RTX 3090 · 24 GB VRAM

Phil automatically falls back to the cloud API if the local endpoint is unavailable. Configure both for redundancy — local for daily use, cloud as backup.

For Students

Rebuild Phil
yourself.

Python 3.11+, Node 20+, an Anthropic API key, a Google Workspace account. No Docker required.

DE: Python 3.11+, Node 20+, ein Anthropic API-Key und ein Google Workspace Konto. Docker ist nicht erforderlich.
1

Clone & install

Get the code and install Python and JavaScript dependencies.

git clone https://github.com/swrobuts/phil-knowledge-navigator
pip install -r backend/requirements.txt
cd frontend && npm install
2

Configure .env

Copy the example file and add your API key. Only ANTHROPIC_API_KEY is required to start.

cp backend/.env.example backend/.env
# Add ANTHROPIC_API_KEY=sk-ant-...
DE: Die .env.example erklärt jeden Parameter. Für den Start reicht der Anthropic API-Key.
3

Run Phil locally

Start backend and frontend in two terminals.

# Terminal 1 — Backend
uvicorn backend.main:app --reload

# Terminal 2 — Frontend
cd frontend && npm run dev

# Open → http://localhost:5173
