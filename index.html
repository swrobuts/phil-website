The Vision

In 1987, Apple released a concept video showing what a personal knowledge assistant could be. It was fiction — none of the required technology existed yet. But the vision was precise, and the name of the assistant was already Phil.

1987 – 2022

The Gap — And the Attempt

The vision was clear. The technology was not. Apple tried — honestly — with the Newton MessagePad in 1993. It failed, not because the idea was wrong, but because the decade was wrong. The Newton is not a failure story. It is proof that the idea was worth pursuing.

Vision: Knowledge Navigator (1987)

  • Intelligent AI agent with natural language
  • Global knowledge access via network
  • Touch interaction — tablet form factor
  • Personalised, learns from the user

Reality: Apple Newton (1993)

  • $699 entry price — too high for unclear value
  • Handwriting recognition failed publicly (Simpsons parody)
  • No internet, no wireless sync, no ecosystem
  • Released 14 months before it was ready

Phil 2026

Today, the technology finally caught up.

Phil is a working personal information manager — not a concept video, not a demo. It manages email, calendar, tasks and knowledge using today's AI tools. It doesn't do everything Apple envisioned. But it does what matters most, right now.

📬

Mail Triage

Phil reads your inbox and categorises messages by priority: VIP / Action Required / FYI / Noise. Each mail gets a summary and a concrete recommended action. Powered by Claude.

📊

Dashboard

A daily briefing at a glance: unread mails by category, today's calendar events, pending tasks, and analytical tiles showing your communication patterns.

📅

Calendar

Natural-language calendar search. Ask "What's next week?" or "When is the faculty meeting?" Phil fetches a full year of events and answers from context.

🤝

Meeting Preparation

Given a calendar event, Phil identifies participants, searches related emails via RAG, and drafts a structured briefing: attendees, relevant messages, proposed agenda.

🧠

Memory & Learning

Phil remembers facts about you across sessions, stored in SQLite + ChromaDB. Thumbs up/down feedback drives RLHF-style learning. Facts are visible and editable.

🔍

Semantic Search

Emails and attachments (PDF, DOCX) are indexed in a vector store. Phil can retrieve semantically similar past correspondence even when keyword search fails.

For Students

Rebuild Phil yourself.

You need Python 3.11+, Node 20+, an Anthropic API key and a Google Workspace account. No Docker required.

DE: Du brauchst Python 3.11+, Node 20+, einen Anthropic API-Key und ein Google Workspace Konto. Docker ist nicht erforderlich.
1

Clone & install dependencies

Get the code and install both Python and JavaScript dependencies.

git clone https://github.com/swrobuts/phil-knowledge-navigator
cd phil-knowledge-navigator
pip install -r backend/requirements.txt
cd frontend && npm install && cd ..
2

Configure your .env

Copy the example file and add your credentials. The only required key is ANTHROPIC_API_KEY for basic chat. Google credentials unlock mail and calendar features.

cp backend/.env.example backend/.env
# Edit backend/.env and add:
# ANTHROPIC_API_KEY=sk-ant-...
DE: Die Datei .env.example erklärt jeden Parameter. Für einen ersten Start reicht der Anthropic API-Key.
3

Run Phil locally

Start the backend and frontend in two terminal tabs.

# Terminal 1 — Backend
uvicorn backend.main:app --reload

# Terminal 2 — Frontend
cd frontend && npm run dev

# Open → http://localhost:5173
